# Food Wastage & Donation Platform

A beginner-friendly full-stack college project for connecting surplus food donations with people who can use them.

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT + bcryptjs

## Run backend
1. Open terminal in `backend`.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Set `MONGO_URI` and `JWT_SECRET`.
5. Run `node server.js`.
6. Open `http://localhost:5000`.

## Run frontend
Open the `frontend` folder with VS Code and use a Live Server extension, then open `index.html` through Live Server.

Never commit `.env` or `node_modules`.
